# Veagle brand kit

The public files the Veagle skill (veagle-style) loads by address. Upload this folder as it is; don't rename anything.

- fonts/   Lama Sans (Regular, Medium, Bold, Black, Black Condensed) and Inter Regular, as WOFF2
- logo/    Every logo version as SVG and transparent PNG, drawn from the official artwork
- photos/  Six real night-match photos from Veagle cameras at Al-Mutawa

Rules for using any of these are in the brand book (دليل هوية Veagle) and in the skill. Approvals: abdulaziz@veagle.sa
